# Tags: how we tag each post

## Tag from our own card first

The team already wrote down what most posts open with. If a post came through the team, its filming card and its post file hold the tags. Look there before you guess anything from a caption.

### Finding the files

- **Filming card:** `scripts/{date}-{short-name}.md` (in a Claude Project: `scripts-{date}-{short-name}.md`). Text, photo and carousel posts have no card.
- **Post file:** `posts/{date}-{short-name}.md` (in a Project: `posts-{date}-{short-name}.md`).
- Match on the **short name**, not the date. The file's date is the planned day, and the owner may have posted on another day. Check the card's `Short name:` line, not just the file name.
- A card name can have a hook type added to the end when there were two hooks for one post (`2026-11-03-nail-trims-warning.md`). If two cards share a short name, ask: "Which card did you film for {post}?" Until they say, tag as if there were no card.
- Shoot plans (`scripts/{date}-shoot-{place}.md`) are not cards. Skip them.

### What to take, and from where

| Our column | From the filming card | From the post file (when there's no card) |
|---|---|---|
| Format | `Format:` | `Type:`: carousel = `Carousel`, photo post = `Photo`, text post = `Text post`. A caption pack is a video: take the format from its card |
| Hook type | `Hook type:` | not in the post file. Tag it from the first line marked `(used)` (or the cover marked `(used)` on a carousel) |
| Spoken first line | `Spoken:` under "The four hooks" | the line marked `(used)` under "First line options", for a text post only |
| Text on screen | `Text on screen:` | the cover marked `(used)`, for a carousel |
| First frame | `First frame:` | `not known` |
| First sound | `First sound:` | `not known` |
| Call to action | the line under "## Call to action" | the `Call to action:` line in the header |
| Plan tag | `Plan tag:` | the plan row's Tag |

Length still comes from the export when it has one: it's the real length, the card's is a guess made before filming.

**The card and the post file disagree on the call to action** (the Copywriter changed it for the caption): tag the card's, because that's what the video says, and mention the difference in one line.

### Did they film it as written?

A card is a plan. The owner may have changed the opening on the day. So at most once per week of numbers, in the same message as the other questions, ask one yes or no: **"Did you film these as written?"** For a week of only text, photo or carousel posts, ask "Did you post these as written?" instead. Never ask it for posts already answered: the answer lives in "Where this came from".

| The owner says | Where this came from | Counts for a strong rule? |
|---|---|---|
| Yes | `from our card` | yes, like `owner told us` |
| No, I changed {part} | fill what they tell you as `owner told us`. Keep the rest from the card as `from our card, not confirmed` | only the parts they told you |
| No, and doesn't say what changed, or no answer yet | `from our card, not confirmed` | no, it's still a guess |

If one post was changed and the rest weren't ("all as written except the nail one"), mark them one by one.

Only the owner's word changes this. A caption that matches one of the card's backup hooks, or differs from the spoken line, is not a sign they filmed it differently: the Copywriter writes captions and may use a backup line.

A `from our card, not confirmed` post still uses the card's words in the log. Then ask for the first line they really said for that post, if it's in your top 3 or bottom 3.

## Hook type and Format

The words for both live in `formats.md`, the team's shared list, with a made-up example for each. Use only those words in the Hook type and Format columns, so the log lines up with the plan, the scripts and the research. If labels drift ("shock", "shocking", "surprise"), the counts stop adding up and the patterns disappear. When a post could be two hook types, `formats.md` says how to pick.

If nothing fits, use `Other` and say what it was in the "What's in each post" table. If `Other` shows up 3 or more times for the same kind of post, tell the owner, but keep using `Other` in the log: the shared list is what every teammate counts by.

If the caption gives no clue to the format (and you have no card, screenshot or word from the owner), write `not known` in the Format column. Don't guess.

## Call to action

One label per post, from this list only, so the counts add up:

| Call to action | What the post asked for | Made-up example |
|---|---|---|
| Comment keyword | comment a word to get something sent by DM | "Comment TRIM and I'll send the price list" |
| Link in bio | tap the link in the bio (to book, buy or sign up) | "Book with the link in my bio" |
| Text, Call, or Text or call | text or ring a number. Use the owner's real route from the profile: only calls is `Call`, only texts is `Text`, both is `Text or call` | "Text 555-0100 to book" |
| DM | send a message | "DM me 'chain' for a spot" |
| Follow or save | follow the account, or save the post | "Save this for brushing day" |
| None | no ask at all | |

Write `not known` when you can't tell (an export with no caption, a screenshot with the caption cut off).

- Where it comes from, in order: the card, the post file, the owner, the caption.
- **Two asks in one post:** tag the one the video says (the card's). With no card, tag the first ask in the caption and mention the second in one line.
- "Swipe to see more" or "watch till the end" is not an ask. Tag it `None`.
- A caption guess counts as `guessed from caption` like any other tag.

## Topic

Topics are free words, but reuse the owner's own topic names from `business-profile.md` ("Topics we post about") when one fits. Keep each topic to 1 to 3 words. Cards don't hold a topic: take it from the plan brief or the caption.

## Tagging from what you can see (no card)

- **Export file only:** you have the caption, length and format, not the video. Tag from the caption and mark "Where this came from" as `guessed from caption`. A caption often isn't what was said or shown.
- **Screenshot of the first frame:** you can tag the first frame and any text on screen. Mark `screenshot`.
- **Owner told you:** mark `owner told us`. This beats a guess.

You don't need every post's four hooks. Ask for them only for the top 3 and bottom 3 posts of the week that have no confirmed card: "To check why these worked or flopped, can you send the first line you said and a screenshot of the first second of each?"

## Talks to "you" or "me"

In the "Spoken first line" and "Text on screen" cells, it's worth noting if the line talks to the viewer ("your", "you") or about the business ("I", "we", "our"). Hooks that talk to "you" usually do better (`four-hooks.md`), and this is an easy pattern to count.
